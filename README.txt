Files are ready for free static website hosting.

QUICK TEST
Open index.html on a computer to preview the quiz. Offline/PWA installation works after the folder is hosted on HTTPS.

FREE HOSTING
Upload all files in this folder together to a static host such as GitHub Pages or Cloudflare Pages.
Do not change the filenames unless you also update index.html.

IPAD
After the hosted site is live:
1. Open its web address in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Name it Ivy Tech Quiz.
5. Launch it from the new Home Screen icon.

QUIZ RULES
- 7 questions
- 5/7 passes
- One attempt per citizen
- No answer-by-answer feedback
- NEXT CITIZEN resets the quiz
